The goal is to create an LLM chat interface that uses a hypermedia approach to
web design.

For the frontend, don't use any frameworks except:
- [htmx](https://htmx.org/)
- [a-h/templ](https://github.com/a-h/templ)
- Basic CSS, adopting code styling to make it easier to read like [css nesting](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Nesting/Using)
