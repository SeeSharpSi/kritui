# Fonts

Inter and JetBrains Mono are bundled as variable WOFF2 fonts with Latin glyphs. Other scripts use the system fallback font.

- Inter: https://github.com/rsms/inter, SIL Open Font License 1.1. See `Inter-OFL.txt`.
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono, SIL Open Font License 1.1. See `JetBrainsMono-OFL.txt`.

WOFF2 files come from Google Fonts. Fonts load from this application without contacting a third-party font service.
